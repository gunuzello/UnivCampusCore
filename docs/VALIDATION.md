## 브라우저 검증

로컬 React → Spring Boot → PostgreSQL 연결을 확인했다.

대표 계정 로그인 → 화면에서 행사 생성 → 행사 공개 → 로그아웃 → 일반 학생 로그인 → 운영진 메뉴 비노출 → 행사 신청 완료 및 정원 증가 확인.

예시 데이터와 이 검증에 사용한 가명 계정은 local 프로필 데이터다.

추가 브라우저 확인: 모바일 프로필에서 새로고침 없이 로그아웃, 대표의 지원서 답변 조회 → 검토 → 합격 처리 → 학생 프로필 결과 및 알림 확인. 운영진 계정에서 신규 회의·안건·결정사항 저장, 과거 회의·인수인계 메모 조회, 지난 내부 일정 등록 → 상세 → 활동 기록 보존을 확인했다.

통합 실행 도구로 DB와 두 서버를 구동했다. 중복 실행 시 포트 안내와 실패 반환을 확인했고 Ctrl+C로 8080/5173 포트가 해제됨을 확인했다. 모바일 363px과 PC 1440px에서 확인한 화면의 가로 넘침이 없었다.

상세 범위와 직접 확인 순서는 `MVP_ACCEPTANCE.md`를 참고한다.

브라우저 확인: 프로그램 생성·공개·상세·저장, 팀 모집 생성·내부 모임 기록·학생 지원·지원 전 내부 공간 비노출, 관심/과목/기술/포트폴리오 저장과 추천 이유, 동아리 모임 주기 저장, 담당 업무 등록·완료와 통합 캘린더 표시. 팀원 수락은 브라우저 자동 승인 검토에서 접근 권한 부여를 이유로 거부되어 실행하지 않았다. 수락 자체와 정원 보호는 자동 테스트로 검증했다. 예시 지원서는 검토 중으로 남겨 두었다.

데스크탑 경로 일부 파일의 읽기가 지연되어 로컬 백업의 변경되지 않은 파일과 현재 수정 파일로 실행 캐시를 준비했다. 원본 파일은 덮어쓰지 않았다. 실행 도구는 파일 크기·수정 시각이 달라진 원본을 캐시에 반영해 임시 폴더에서 실행하며 정상적으로 두 서버가 준비됨을 확인했다. 코드 수정/브랜치 전환 후 재실행해야 변경이 반영된다.

AI FIND, AI 제공자 연결, 학교 인증과 외부 API 연동은 요청에 따라 제외했다. HTML의 화면을 픽셀 단위로 대조한 완료 상태는 아니다.

## PC·모바일 화면 마감

`feat/responsive-ui-polish`에서 기존 코랄 색상·반투명 카드 스타일을 유지하면서 메뉴, 폼, 카드, 탭, 캘린더를 보강했다. 모바일 하단 메뉴는 홈·찾기·캘린더·소속·내 정보 5개이며, 상단 메뉴에서 행사·모집·대여·회의·지난 활동에 접근한다. 메뉴는 페이지 이동·외부 클릭·Escape로 닫힌다.

모바일 캘린더는 날짜별 일정 개수를 표시하고 선택한 날짜의 일정 목록을 보여준다. 자정 기준 날짜 범위, 이전·다음·오늘 이동 시 선택 날짜 갱신, 일정 상세 링크를 확인했다. PC에는 기존 월간 일정 내용을 유지한다. 날짜 입력의 지역 시간 변환도 보정했다.

브라우저에서 390px 주요 화면 8개(홈·찾기·소속·프로필·대여·팀·프로그램·회의 상세)의 가로 넘침 없음, 320px 동아리 소속 화면의 넘침 없음, 768px 찾기의 키보드 화살표 탭 이동과 넘침 없음, 1440px 캘린더 배치를 확인했다. 폼 글자 크기, 터치 영역, 안전 영역, 포커스와 본문 이동 링크를 보강했다. 소속 화면의 중복 React 키 오류도 수정했다. 프론트엔드 타입 검사 및 배포 빌드 통과. 백엔드 코드는 변경하지 않았으며 앞선 자동 테스트 36개 통과 결과를 유지한다. 실제 iPhone·Android 기기 검증이나 모든 HTML 화면의 픽셀 단위 일치 검증을 의미하지 않는다.

Git Fetch 실패의 원인은 `.git/refs/remotes/origin/HEAD 2`라는 잘못된 중복 참조였다. 중복 파일을 `/private/tmp/ucc-ref-recovery-20261005`에 백업하고 정상 참조만 유지한 뒤 Fetch 및 원격 기본 브랜치 참조 갱신이 성공했다. 커밋과 작업 파일은 보존했다. 중복 파일 생성 원인은 확정하지 않았다.
