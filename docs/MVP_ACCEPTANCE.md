# 로컬 MVP 완료 기준과 확인 방법

2026-10-05. 완료 범위는 학생회 운영 기능이 React → REST API → PostgreSQL로 동작하는 로컬 MVP다. 배포와 제외 기능은 포함하지 않는다.

## 구현 상태

| 영역 | 실제 구현 | 확인 근거 |
|---|---|---|
| 회원·프로필 | 가입, 로그인, 로그아웃, 조회·수정, 비밀번호 암호화, 세션·CSRF | 인증 테스트, 브라우저 계정 전환 |
| 조직 | 생성·수정, 구성원 추가·제거, 조직별 역할, 마지막 대표 보호 | 조직 권한 테스트, 대표·운영진·학생 화면 |
| 행사 | 질문·기간·정원 설정, 초안·공개·마감·취소·완료, 신청·취소, 신청자 조회·참가 상태 | 서비스 규칙 테스트, 마지막 자리 동시 신청 테스트, 브라우저 생성·공개·학생 신청 |
| 모집 | 공고·질문, 지원·취소, 지원서 상세, 검토·합격·불합격 | 모집 테스트, 브라우저 검토→합격→학생 결과 확인 |
| 회의 | 참석 대상, 안건, 내용, 결정사항, 수정·조회 | 내부 권한 테스트, 브라우저 신규 회의 저장·지난 회의 조회 |
| 일정 | 월·주 통합 캘린더, 내부 일정 생성·수정·삭제·상세 | 권한 테스트, 브라우저 지난 일정 생성·상세 조회 |
| 기록·재사용 | 완료 행사·종료 모집·지난 회의·내부 일정, 연도 탐색, 행사 복제 | 기록·복제 테스트, 브라우저 지난 일정 보존 |
| 자료·인수인계 | 자료 링크 추가·수정·삭제, 조직별 인수인계 메모, 다른 구성원에게 기록 공개 | URL·조직 경계 테스트, 운영진 계정의 기록·메모 조회 |
| 알림·개인 내역 | 신청·지원 및 변경 알림, 본인 신청·지원 상태 | 사용자별 내역 테스트, 학생 결과·알림 확인 |
| 실행 | DB와 두 서버 통합 실행, 시작 실패·포트 충돌 안내, Ctrl+C 종료 | 통합 실행, 중복 실행 거부, 두 서버 포트 해제 확인 |

자동 테스트 12개 통과, 실패·오류·건너뛰기 0개. TypeScript 검사와 Vite 빌드 통과. 테스트 DB는 개발 데이터와 분리된 `ucc_test`다.

## 직접 사용해 보기

1. 저장소에서 `./scripts/dev.sh`를 실행하고 http://127.0.0.1:5173/ 을 연다.
2. `leader@ucc.local`로 로그인한다. 비밀번호는 `ucc-local-2026!`이다.
3. 소속 → 행사에서 질문과 기간을 넣어 새 행사를 만들고 공개한다.
4. 프로필에서 로그아웃한 후 `student@ucc.local`로 로그인한다. 같은 비밀번호다.
5. 공개된 행사에 답변을 제출한다. 프로필에서 신청 상태를 확인한다.
6. 대표 계정으로 돌아와 신청자 상세를 열고, 신청 마감 후 참가 상태를 관리한다. 행사 종료 시각 이후 완료 처리하면 지난 활동에 남는다.
7. 모집도 공고 생성 → 질문 설정 → 공개 → 학생 지원 → 운영진 검토·결과 처리 → 학생 결과 확인 순서로 사용한다.
8. 소속 → 회의에서 기록을 저장하고 캘린더에서 연결을 확인한다. 지난 회의와 종료된 내부 일정은 지난 활동에서도 조회된다.
9. 지난 활동에서 자료 링크·인수인계 메모를 남긴다. 같은 조직의 `staff@ucc.local`도 기존 기록을 볼 수 있다.
10. 지난 행사를 복제할 때 새 날짜와 신청 기간을 설정한다. 과거 신청자는 복제되지 않는다.

처음 실행 시 제공되는 모든 사용자 정보는 가명이다. 브라우저 검증에서 만든 “로컬 검증” 일정·회의와 “브라우저 검증 행사”도 로컬 예시 데이터다. 일반 회원은 자동으로 조직 구성원이 되지 않는다. 대표가 소속 화면에서 회원의 이메일로 구성원을 추가한다.

## UI 기준과 범위

원본 `docs/prototype/ucc_final_v8.html`을 보존한다. 코랄색, 유리 카드, 네 가지 주요 메뉴, 학생회 업무의 정보 구조를 반영했다. PC에서는 사이드바, 모바일에서는 하단 메뉴를 사용한다. 모바일에서는 소속의 행사·모집·회의·지난 활동 링크로 내부 업무 화면에 접근한다.

이번 확인 화면: 모바일 363px의 프로필·계정·운영 화면과 PC 1440px의 활동 기록. 해당 화면에서 가로 넘침이 없음을 확인했다. 모든 원본 화면을 픽셀 단위로 동일하게 복제하거나 모든 기기·브라우저를 검증한 것은 아니다.

이 문서는 초기 학생회 MVP의 완료 기준이다. 이후 사용자 요청으로 프로그램·팀·동아리·대여·업무·건의·개인 관심 기능을 확장했다. 최신 범위는 FEATURE_ROADMAP.md를 참고한다. AI FIND, 학교 인증, 결제, 채팅, 외부 API 직접 연동, 모바일 네이티브 앱은 제외한다. 원격 CI와 배포는 로컬 검증 완료 기준에 포함하지 않는다.
